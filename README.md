# مَرسى – MARSA (v4)

نظام تجريبي لإدارة المخاطر والإنذارات البحرية في السواحل السعودية، يعمل على **بيئة بيانات اختبار منظمة** (TEST DATA ENVIRONMENT). البيانات موجودة عند فتح النظام، ووظائفه حقيقية في منطقها: كل عملية تحدّث قاعدة بيانات الاختبار وتُسجَّل في سجل العمليات.

> لا يوجد اتصال فعلي مع المركز الوطني للأرصاد أو AIS أو محطة كراتشي أو السفن والموانئ. مَرسى لا تبث رسائل NAVTEX ولا ترسلها إلى كراتشي، ومحرك التحليل قواعد واضحة وليس نموذج ذكاء اصطناعي مدرّبًا. هويات السفن اختبارية (IMO يبدأ بـ TEST-، وMMSI يبدأ بـ 999). التوصيات استشارية (انظر بيان المسؤولية داخل النظام).

## بيانات الاختبار
| المجموعة | المحتوى |
|---|---|
| WeatherObservations / WeatherForecasts | ٨ مناطق في البحر الأحمر والخليج العربي: رياح وأمواج وتيارات (سرعة واتجاه)، رؤية، حرارة، توقعات ساعية ٤٨ ساعة، وموثوقية لكل قيمة. القيم متسقة زمنيًا وتتضمن ثلاثة أنظمة جوية (منخفض على وسط البحر الأحمر، رياح شمال على الخليج، غبار وتيارات في جازان). |
| Vessels | ٢٤ سجل سفينة: الاسم، IMO اختباري، النوع، الموقع، السرعة، الاتجاه، الغاطس، المغادرة، الوجهة، المسار، الوصول المتوقع، الحالة، قناة الإنذار. |
| Ports | ٧ موانئ سعودية: الحالة، الازدحام، الطاقة، الظروف، القيود (قابلة للتعديل). |
| MaritimeRisks / AffectedVessels | مخاطر محسوبة بالقواعد + سجلات مخاطر + مخاطر يدوية + مخاطر حالة الموانئ، والسفن داخل المنطقة أو الداخلة خلال ٤٨ ساعة أو التي يتقاطع مسارها. |
| Alerts / DeliveryRecords | مسودة ← بانتظار الاعتماد ← معتمد ← جاهز للإرسال ← أُرسل في بيئة الاختبار ← تم الاستلام ← تم التأكيد ← منتهي. |
| Bulletins / NavtexMessages | نشرات (جوية، رياح وأمواج، إغلاق ميناء، قيد ملاحي) بنطاق محلي/ساحلي/دولي، وأداة تنسيق NAVTEX للاختبار مع التحقق والتصدير TXT/JSON. |
| AlternativeRoutes | مسار حالي مقابل بديل (مسافة، زمن، الخطر المتجنب، السبب، الفحوصات)، وصلاحيته دائمًا «غير متحققة». |
| Constraints | قيود ملاحية تجريبية (أعماق اختبار ومنطقة محظورة) تُستخدم في المسارات البديلة. |
| AuditLogs | سجل عمليات متسلسل بـ SHA-256. |

## التشغيل
| الطريقة | الأمر |
|---|---|
| خادم (عدة أجهزة) | `npm start` ثم `http://localhost:8080` (Node.js 22.13+، دون مكتبات خارجية، SQLite مدمجة) |
| ملف واحد بلا خادم | `npm run build` ثم افتح `dist/marsa.html` |
| الاختبارات | `npm test` (١١ اختبارًا للرحلة الكاملة والتعديلات والتحقق) |

إعادة تهيئة البيانات من «بيانات الاختبار ← إعادة تهيئة بيانات الاختبار».

## التكامل المقترح (Proposed Integration)
- **المركز الوطني للأرصاد:** نموذج بيانات موحد، `POST /api/integrations/ncm/weather` بمفتاح `X-Integration-Key`، تحقق من المدى والحقول الحرجة والحداثة، ورفض السجلات غير الصالحة مع الأسباب.
- **NAVAREA IX / NAVTEX:** النطاق الدولي يوجَّه إلى منسق المنطقة التاسعة، والمحلي/الساحلي إلى محطة NAVTEX المختصة. الإرسال يمر فقط إلى نقطة `proposed://` داخل بيئة الاختبار.
- **شاشة السفينة:** تستقبل الإنذارات من قاعدة بيانات الاختبار، والتأكيد يظهر فورًا عند ضابط الميناء.
