# مَرسى – MARSA (v3)

منصة ذكية للتنبؤ بالمخاطر البحرية واستمرارية الموانئ والتحذيرات الملاحية. تستقبل توقعات الأرصاد وبيانات الموانئ والسفن، وتتنبأ بالمخاطر خلال ٤٨ ساعة، وتقترح قرارات تشغيلية ومسارات بديلة. **كل قرار رسمي يتخذه إنسان مخوّل** ويُسجَّل مع الإقرار ببيان المسؤولية.

> مَرسى **لا تبث** رسائل NAVTEX ولا تصدر تحذيرات NAVAREA، ولا تدّعي اتصالًا حيًا غير موجود، ولا تتصل بأنظمة ملاحة السفن أو تتحكم بها. البيانات الموسومة «محاكاة / SIM» صادرة من بيئة العرض.

## الواجهتان

الصفحة الرئيسية فيها أيقونتان فقط:

**ضابط الميناء** – خمسة تبويبات:
1. **خريطة تتبع السفن:** مواقع السفن (محاكاة AIS)، بيانات السفينة عند الضغط عليها، وتمييز السفن المعرضة للخطر.
2. **التنبؤ بالمخاطر ٤٨ ساعة:** السفن المتوقع تعرضها للخطر، مع نوع الخطر وموقعه ووقته ومستواه والتوصية.
3. **الإنذارات المحلية:** تم إنشاؤه ← بانتظار الإرسال ← تم الإرسال، مع حالة كل سفينة (تم الإرسال / تم الاستلام / أكد الطاقم / تعذر الإرسال) ووقتها. مستقلة عن NAVTEX.
4. **النشرات والإشعارات الملاحية:** من بيانات المركز الوطني للأرصاد إلى الموانئ المعنية ومحطة كراتشي حسب النطاق: قيد الإنشاء ← جاهزة ← أرسلت إلى الميناء / كراتشي ← تم تأكيد الاستلام ← بانتظار الإصدار الرسمي ← صدرت رسميًا. مَرسى تجهّز وتوجّه فقط؛ البث الرسمي للموانئ ومحطة كراتشي.
5. **المسارات البديلة:** مرتبطة بإنذارات مَرسى المحلية. تُرسل مع الإنذار إذا كانت بياناتها كافية ومستوى خطرها منخفضًا أو متوسطًا، وإلا تبقى توصية تحتاج اعتماد الضابط.

**جسر السفينة:** إنذار صوتي (جرس) ونافذة كبيرة بلون الخطورة مع زر تأكيد الاستلام، وخريطة منطقة الخطر (أحمر) والمسار الحالي والمقترح، وسجل الإنذارات، وزر «اختبار الإنذار».

## التشغيل والنشر

| الطريقة | الأمر | ملاحظات |
|---|---|---|
| خادم كامل (موصى به، يدعم عدة أجهزة) | `npm start` ثم `http://localhost:8080` | Node.js ‏22.5+ دون مكتبات خارجية. قاعدة البيانات `data/marsa.db` (SQLite). يطبع عنوان الشبكة المحلية لفتحه من الجوال. |
| بيانات طقس مفتوحة حقيقية | `npm run start:openmeteo` | توقعات ساعية ٤٨ ساعة من Open-Meteo بدل المحاكي، وتُوسم أنها ليست من المركز الوطني. تتطلب إنترنت. |
| ملف واحد بلا خادم | `npm run build` ثم `dist/marsa.html` | كل شيء داخل المتصفح؛ البيانات لكل متصفح على حدة. |
| الاختبارات | `npm test` | ٧ اختبارات تغطي سيناريو جدة كاملًا، باب المندب، العزل والصلاحيات، حماية بيانات الاعتماد، وكشف العبث بالسجل. |

**النشر على خادم سحابي** (Render أو Railway أو Fly.io أو أي VPS):
1. ارفع المجلد إلى مستودع Git، واختر خدمة Node.js بالأمر `npm start`.
2. اجعل `data/` قرصًا دائمًا (Persistent Disk) حتى لا تضيع القاعدة عند إعادة التشغيل.
3. متغيرات البيئة: `PORT` (تضبطه المنصة عادة)، `MARSA_DB=/data/marsa.db`، `MARSA_SECRET_KEY` (‏64 رمزًا ست عشريًا لتشفير بيانات الاعتماد: `openssl rand -hex 32`)، `MARSA_INTEGRATION_KEY` (مفتاح نقاط التكامل)، `MARSA_DEMO=0` للإنتاج (يخفي حسابات العرض ويمنع إعادة الضبط).
4. ضع HTTPS أمام الخادم (توفره المنصات السحابية تلقائيًا).
5. النسخ الاحتياطي: `GET /api/backup` بحساب المدير، والفحص: `GET /healthz`.

## الأمان
- كلمات مرور مجزأة بـ scrypt، وجلسات برمز حامل مدتها ١٢ ساعة، وحد لمحاولات الدخول ولمعدل الطلبات.
- صلاحيات حسب الدور والجهة والميناء (أقل صلاحية)، وتحقق من المدخلات في طبقة الخدمة.
- بيانات اعتماد التكاملات مشفّرة AES-256-GCM في القاعدة ولا تظهر إلا مقنّعة.
- سجل تدقيق متسلسل بـ SHA-256 (أي تعديل يكسر السلسلة) ومحمي من التعديل والحذف على مستوى القاعدة؛ القرارات غير قابلة للتعديل.

## الدخول التجريبي
الدخول من الأيقونتين مباشرة (حساب ضابط الميناء التجريبي، أو جسر أي سفينة). يُعطَّل بـ `MARSA_DEMO=0`. الحسابات القديمة (`admin/admin` وغيرها) ما زالت في الخادم لواجهة البرمجة.

## البنية
```
shared/core.js     الجغرافيا والممرات، أقصر مسار يتجنب الخطر، تصنيف مستوى التحذير، الموانئ وحدودها، مناطق الانتظار، SHA-256
shared/predict.js  محرك التنبؤ (نموذج أولي قائم على القواعد): مستوى الخطر الساعي، الطاقة، الطوابير، التأخير، محاكاة الاستمرار/التقييد/الإغلاق
shared/service.js  طبقة الأعمال: التحذيرات الثلاثة، الاعتمادات، التسليم والتأكيد والتصعيد، المسارات، الإشعارات، التدقيق، التكاملات
server/            خادم HTTP + SQLite + المصادقة + نقاط التكامل + النسخ الاحتياطي
web/               الواجهة (عربي/إنجليزي)، الخريطة، التقارير PDF وExcel/CSV دون مكتبات
```

## نقاط التكامل (آلة-لآلة، بترويسة `X-Integration-Key`)
- `POST /api/integrations/forecast` توقعات ساعية (المخطط في `/api/openapi.json`).
- `POST /api/integrations/authority-callback` تحديث حالة تحذير من الجهة المختصة (منشور/محدّث/ملغى/مرفوض + المرجع الرسمي).

لا توجد حاليًا واجهات رسمية من المركز الوطني للأرصاد أو الجهة البحرية أو مزود AIS؛ وضع «إنتاجي» لا يُجري أي اتصال حتى تتوفر مواصفات الواجهة الرسمية.

## الافتراضات
سعر الوقود 620 دولار/طن، 3.75 ريال/دولار، النقل البري 6.5 ريال/كم، حد إشغال الميناء البديل 88٪، مهلة التأكيد 5 دقائق (قابلة للتعديل)، نصف قطر المنطقة المحلية 25 ميلًا. حدود التشغيل الافتراضية: هبات 22/27 عقدة، موج 2/3 م، رؤية 1/0.5 ميل (تقييد/إغلاق)، وقابلة للتعديل لكل ميناء. قائمة محطات NAVTEX في المنطقة التاسعة مأخوذة من مصادر عامة وتحتاج تحققًا رسميًا.
